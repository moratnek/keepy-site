よくある質問

無料のままどこまで使えますか？
サブスク3件・クレジットカード1枚・口座1件まで無料で登録できます。Face ID・暗号化・バックアップなどのセキュリティ機能は、無料のままフルにお使いいただけます。件数を増やしたいときや、終活ノート・家族への引き継ぎ配布・モノや書類の管理を使いたいときにプレミアムをご検討ください。
プレミアムは月額ですか？追加課金はありますか？
一度きりのお支払い（買い切り）です。月額料金も、あとからの追加課金もありません。データは端末内にあり運用サーバーを持たない設計のため、維持費を利用者に請求する必要がないからです。
早期割引はいつまでですか？
先着100名、または公開から1か月後のどちらか早い方までを予定しています。その後は ¥3,480 になる見込みです。買い切りのため、割引価格で購入されたあとに差額を請求することはありません。
古いiPhoneでも使えますか？
iOS 17 以上が必要です。お使いの iPhone が iOS 17 に対応していれば（設定 → 一般 → ソフトウェアアップデート で確認できます）、アップデートのうえご利用いただけます。対応していない端末ではインストールできません。
iPadでも使えますか？
Keepy は iPhone 向けのアプリです。iPad でも互換モード（iPhone サイズの表示）で動作しますが、iPad 専用の最適化はしていません。iPhone でのご利用を前提に設計しています。
サブスク以外も登録できますか？
はい。毎月決まった額が続けて引かれるものなら、同じように登録できます。あと払いサービスの定額分割払い、携帯の端末代金、保険の月払い、習い事の月謝など。

「契約期間」を入れておけばいつ終わるのかも一緒に管理でき、終了前に通知でお知らせします。なお、プリセットにないサービスは、名前と金額を手で入力して登録できます。
Keepyでサブスクを解約できますか？
Keepy でできるのは「解約した」と記録することまでです。実際の解約手続きは、契約先のサービス側で行っていただく必要があります。

詳細画面に手続き先へのリンクがあります。App Store（Apple ID決済）のように管理画面が決まっているものはその画面が直接開き、キャリア決済などサービスごとに手続き先が違うものは「サービス名 解約方法」の検索結果が開きます。手続きを終えたら Keepy 側でも「解約済み」にすると、月額合計から外れて節約額に反映されます。
解約したサブスクはどこで確認できますか？
解約済みのサブスクはサブスク一覧の下部「解約済み」セクションにまとめて表示されます。再開する場合は詳細画面から「再開」ボタンをタップしてください。解約済みサブスクは月額合計の計算から除外され、解約で節約できた金額がサマリーカードに表示されます。
レポート画面とは何ですか？
レポート画面は、月ごとの支出をグラフで振り返れる画面です。サブスク一覧の上部にある「レポート」タブからアクセスできます。支払済みと予定を分けて集計し、カテゴリ別の内訳も確認できます。
決済方法の「経由サービス」とは何ですか？カード払いはどれを選べばいいですか？
「経由サービス」は、Apple ID決済やd払いのように、サブスクとカードの間に入る決済サービスのことです。たとえば App Store で契約していて楽天カードから引き落とされるサブスクは、経由サービス「Apple ID決済」＋引き落とし元「楽天カード」の組み合わせで登録します。カードや口座から直接引き落とされる場合は、経由サービス「なし」を選んで引き落とし元だけを設定してください。選べる経由サービスは、Apple ID決済・Google Play決済・d払い・auかんたん決済・ソフトバンクまとめて支払い・その他キャリア決済・PayPal・その他です。詳しくは マニュアルの「決済方法」 をご覧ください。
「はじめる準備」（オンボーディング）とは何ですか？
初めて使うとき、口座・カード・サブスクの登録と家族への引き継ぎを順番にご案内する画面です。あとで続きをやる場合は、ホームの「はじめる準備」チェックリストから各項目を登録できます（すべて済むと自動で消えます）。
ウィジェットが更新されません。
ウィジェットはデータを変更したときと、毎朝9時に更新されます。iOS の判断で表示が遅れることがあるため、すぐに反映したいときは Keepy を一度開いてください。

ホーム画面を長押し → 「＋」から「Keepy」を選ぶと追加できます（小・中の2サイズ）。「通知に金額・サービス名を出さない」をオンにしている場合は、ウィジェットでも金額が伏せられます。
通知が届きません。
iOSの「設定 → 通知 → Keepy」から通知が許可されているかご確認ください。また、Keepy内の「設定 → 通知設定」でも各通知のオン・オフを確認できます。
通知が多いので減らしたいです。
「設定 → 通知設定」で「更新前の通知」「月次・年間レポート」「カード引き落とし通知」をそれぞれオフにできます。更新前の通知は、サブスクごとに「何日前に通知するか」も変更できます（登録・編集画面の「更新の何日前に通知」）。

同じ画面の「通知に金額・サービス名を出さない」をオンにすると、ロック画面に内容が出なくなります。
カード引き落としの通知に出る金額が、実際の請求額と違います。
この通知の金額は「Keepy に登録したサブスク分の合計」＝参考値です。実際の請求額とは一致しません。

カードの実際の引き落としは各社の締め日の体系で決まり、買い物などサブスク以外の利用も含まれるためです。Keepy は登録されている分しか知らないため、金額を断言しない表記にしています。
データはどこに保存されますか？
すべてのデータはお使いの端末内にAES-256暗号化されて保存されます。あなたが登録した記録が外部に送られることは一切ありません。開発者もデータを閲覧することはできません。
※ サービスのロゴを表示するときだけ、サービス名（例: netflix.com）を送って画像を取得します。外に出る通信の全部
アプリを開くたびに認証を求められます／求められません。
「設定 → セキュリティ情報」の自動ロックで、離れてからロックするまでの時間をすぐ・30秒・1分（初期設定）・5分・10分から選べます。すぐにロックしたい場合は「すぐ」、少し離れただけで認証を求められたくない場合は長めにしてください。
Face IDで認証できません。
Face IDの認証に失敗した場合、iOSのデバイスパスコード入力画面に自動で切り替わります。ご家族の方がご利用の場合は、認証画面下部の「ご家族の方はこちら」からパスコードでログインしてください。
誤ってデータを削除してしまいました。
削除したデータはゴミ箱に移動し、設定で指定した期間（デフォルト90日）保持されます。「設定 → データ管理 → ゴミ箱」から復元することができます。
復活カギ（リカバリーコード）をなくしてしまいました。
いまお使いの iPhone が手元にあれば、もう一度確認できます。「設定 → セキュリティ情報 → 復活カギを確認する」で8語を表示できますので、控え直してください。

端末を紛失・初期化したあとに復活カギも分からない場合は、バックアップファイル（.enc）を開く手段がなくなり、復元はできません（開発者にも開けない設計です）。復活カギは 1Password などのパスワード管理アプリか、紙に書いて重要書類と一緒に保管してください。
機種変更したらデータが消えてしまいました。
機種変更前に「設定 → バックアップ → バックアップを書き出す」からデータをバックアップしてください。新しい端末での初回起動時に「バックアップから復元」を選択してデータを引き継ぐことができます。
機種変更したらプレミアムは引き継がれますか？
同じ Apple ID をお使いであれば自動で引き継がれます。反映されないときは、アプリ内の購入画面にある「購入を復元する」をタップしてください。※プレミアムの権利とアプリのデータは別物です。データの引き継ぎにはバックアップと復活カギが必要です。
アプリを削除したらデータはどうなりますか？
端末内のデータは消えます。Keepy はデータを外部サーバーに置かないため、端末から消すと復元のもとがなくなります。

入れ直す予定がある場合や、機種変更の前には、必ず「設定 → バックアップ」で暗号化ファイル（.enc）を書き出し、復活カギ（8語）も控えてから削除してください。この2つが揃っていれば、新しい端末で元どおりに戻せます。
この端末のデータを初期化するには？
「設定 → データ管理」から端末内のデータを初期化できます（暗号化キーを削除し、最初のセットアップ画面に戻ります）。初期化するとこの端末の内容は消えるため、事前にバックアップと復活カギの控えをご用意ください。
家族には何が見えますか？
家族モードは「見るだけ」です。追加・編集・削除、バックアップや家族の管理、セキュリティ設定の変更はできません。

見える範囲はご家族ごとに設定できます。「サブスクを見せる」「資産を見せる」はそれぞれオン・オフでき、iPhoneのパスコードを見せる設定は既定でオフです（必要な方にだけ、登録時の警告を読んだうえでオンにしてください）。ご家族には手続き用のチェックリストが表示され、済んだものに「手続き完了」を付けられます。
家族への引き継ぎはどう配布しますか？
共有フォルダに暗号化ファイル（.enc）と引き継ぎガイドを書き出し、宛先ごとに自動で作られる「Keepy○○（お名前）」フォルダで個別に共有します。各ガイドには宛先ご本人の家族パスコードだけが載ります。設定の流れは 引き継ぎガイド へ。
別の端末で、引き継いだデータを見るには？
ご家族が新しい端末で見るには、ロック画面下部の「別のバックアップから復元」を選び、共有された暗号化ファイルと復活カギ（8語）で復元します。手順は 引き継ぎガイド をご覧ください。
家族がパスコードを忘れてしまいました。
オーナーが「設定 → 家族を管理 → 該当する家族 → パスコードをリセット」からパスコードをリセットできます。リセット後、家族が次回ログイン時に新しいパスコードを設定できます。
不具合が起きたときは？
「設定 → お問い合わせ」からメールで報告できます。このとき、直近のエラー内容（画面名・メッセージ・時刻）とアプリ／iOS／端末の情報が自動で本文に添えられます。カード番号や口座などの個人情報はスクラブ（伏字）され、載りません。※アプリが強制終了するクラッシュは自動記録の対象外です。
